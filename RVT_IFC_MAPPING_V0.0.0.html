Редактор Pset

1. Скачать / Сгенерировать схемы IFC

Попытка получить схему через API bSDD. Если API недоступен из-за ограничений браузера, файл сгенерируется автоматически из встроенной спецификации.

2. Загрузить локальные JSON-схемы в приложение

Выберите сохраненный JSON-файл. Список классов сохранится в браузерном хранилище (`localStorage`).

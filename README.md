## Инструменты маппинга параметров Revit в IFC

Данный репозиторий содержит два HTML-файла, представляющих собой веб-инструменты для настройки правил экспорта (маппинга) параметров из Autodesk Revit в формат IFC. Оба приложения работают полностью в браузере (не требуют установки сервера или дополнительных зависимостей) и используют  JavaScript, HTML и CSS.

Ниже представлено подробное описание функционала каждого файла, их различий и инструкций по использованию.

---

## В чем разница между файлами?

1. **Подход к работе:** 
   * **IFC_Mapping_Editor (Файл 1)** работает "с чистого листа". Вы вручную печатаете и название параметра Revit, и название свойства IFC. Это редактор конечного текстового файла.
   * **Revit_IFC_Mapping (Файл 2)** отталкивается от существующих данных. Базой служит ваш реальный ФОП из Revit, к параметрам которого вы привязываете свойства IFC. 
3. **Сохранение состояния:** Файл 2 позволяет сохранять рабочую среду в формате `.json` (проект целиком), в то время как Файл 1 работает только с финальным текстовым выхлопом (`mapping.txt`).

## Файл 1: IFC_Mapping_Editor
Этот файл представляет собой редактор базового уровня для прямого создания и редактирования пользовательских наборов свойств (Property Sets). 

### Функционал
* **Управление наборами (Psets):** Позволяет создавать новые Pset, задавать им имя, режим (I или T) и указывать класс IFC (IfcClass). 
* **Добавление параметров:** В каждый Pset можно добавлять параметры, указывая имя свойства IFC (IFC Property), тип данных (Text, Real, Integer, Boolean, Lenght, Area) и соответствующий параметр Revit (Revit Parameter).
* **Управление интерфейсом:** Реализована функция перетаскивания (Drag-and-Drop) для изменения порядка как самих Pset, так и параметров внутри них. Также доступен поиск по имени Pset и IfcClass.
* **Импорт и экспорт:** Пользователь может загрузить существующий файл маппинга в формате `.txt` или сохранить текущую конфигурацию в новый `.txt` файл.

### Как использовать
1. Откройте файл в браузере.
2. Нажмите кнопку "Создать Pset" для добавления нового набора, либо "Импорт маппинга" для загрузки текстового файла с существующими настройками.
3. Заполните поля параметров вручную. 
4. После завершения настройки нажмите "Сохранить маппинг".

## Файл 2: Revit_IFC_Mapping
Этот файл является более продвинутым инструментом, который выстраивает процесс маппинга вокруг Файла общих параметров (ФОП) Revit и библиотеки шаблонов.

### Функционал
* **Разделение на вкладки:** Интерфейс разделен на две основные рабочие зоны: "ФОП → IFC" и "Шаблоны Pset".
* **Импорт ФОП:** Поддерживает загрузку Файла общих параметров Revit (форматы `.txt`, `.txtf`, `.csv`), автоматически группируя параметры согласно их категориям в ФОП.
* **Система шаблонов:** Вкладка "Шаблоны Pset" позволяет создавать библиотеку ожидаемых IFC-свойств и их типов.
* **Умный маппинг и автозаполнение:** При настройке параметров на вкладке "ФОП → IFC", система использует включенную опцию "Использовать шаблон параметров" для вывода подсказок (автозаполнения) из библиотеки шаблонов. Тип IFC при этом подставляется автоматически.
* **Валидация типов:** Приложение сравнивает исходный тип данных параметра Revit с выбранным типом IFC и отображает статус (галочка при совпадении, предупреждение при конфликте типов).
* **Комплексный экспорт:** Позволяет импортировать/экспортировать маппинг ФОП, отдельно импортировать/экспортировать шаблоны, а также сохранять весь проект целиком в формате `.json`.

### Как использовать
1. Откройте файл в браузере.
2. Перейдите на вкладку "Шаблоны Pset" и создайте/импортируйте библиотеку свойств.
3. Вернитесь на вкладку "ФОП → IFC" и импортируйте свой ФОП Revit.
4. Пользуясь строкой поиска и фильтрами ("Все", "Замапленные", "Незамапленные"), начните сопоставлять параметры.
5. При вводе названия IFC-свойства обращайте внимание на выпадающие подсказки из шаблонов.
6. Сохраните результат через "Экспорт проекта" (сохранит в `.json` и ФОП, и шаблоны) или сохраните непосредственно итоговый текстовый маппинг.
